# Simple Studio

Браузерная студия для мини-роликов с минималистичными изометрическими человечками
(стиль — референсы в `reference/`).

- **Сцены** — идут подряд на таймлайне, как клипы в CapCut: длительность, порядок, переходы (склейка / через чёрный / через белый), шаблоны «Спальня», «Гостиная», «Офис», «Парк» и большие уличные «Улица», «Остановка», «Двор» с машинами и прохожими.
- **Персонажи** — «он» / «она», цвет, рост. 37 анимаций: жесты, эмоции, движение, позы (сидеть, лежать, на колено…).
- **Перемещение** — режим «● Запись движения»: ставите плейхед, тащите персонажа — создаётся ключ, между ключами он сам идёт/бежит и поворачивается по ходу.
- **Декорации** — интерьер, улица (дорога, переход, тротуар, фонарь, светофор, дома, магазин, остановка…) и транспорт: седан, хэтчбек, пикап. Машины ездят по ключам с разгоном и торможением, колёса крутятся.
- **Камера** — по умолчанию изометрия как на референсах; вращение/панорама/зум мышью, ключи камеры для пролётов.
- **Текст** — субтитры и заголовки на отдельной дорожке.
- **Звук** — загрузка MP3/WAV/…, несколько дорожек, обрезка, громкость, фейды, волна.
- **Экспорт** — покадровый рендер в MP4 (H.264 + AAC) через WebCodecs, 720p–1440p, 16:9 / 9:16 / 1:1 / 4:3.
- Undo/redo, автосохранение в браузере, сохранение/открытие проекта файлом (`.studio.json`, звук внутри).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/
```

Нужен Chrome / Edge (WebCodecs). В других браузерах экспорт уходит в WebM в реальном времени.

## Горячие клавиши

Пробел — play/pause · S — разрезать клип · Q/E — поворот · Ctrl+D — дублировать · Del — удалить ·
Ctrl+Z / Ctrl+Y — отмена/повтор · ←/→ — кадр (Shift — секунда) · Ctrl+колесо на таймлайне — масштаб.

## Устройство

- `src/engine/` — three.js: фигура и суставы (`figure.ts`), библиотека поз/анимаций (`poses.ts`), декорации (`props.ts`), вычисление состояния по времени (`evaluate.ts`), сборка сцены (`runtime.ts`), титры/переходы (`overlay.ts`).
- `src/ui/` — React-интерфейс: библиотека, вьюпорт, инспектор, таймлайн, экспорт.
- `src/export/exporter.ts` — рендер кадров и сведение звука в MP4 (mediabunny).
- `gallery.html` — отладочный лист всех поз (`/gallery.html?az=2.36&el=0.15` — вид сбоку).
